# Dynamic Island 400

Android prototype for an iPhone-style Dynamic Island overlay, tuned for HONOR 400.

## Build
The GitHub Actions workflow builds a debug APK automatically. No Android Studio is required for the user.

## Install
1. Open the Actions tab and wait for the build to finish.
2. Download the APK artifact.
3. Install it on the HONOR 400.
4. Open the app, allow "Display over other apps", then start the island.

## Important
This is v0.1.0. The exact camera-hole geometry must be calibrated on the physical HONOR 400. Future work can add music, charging, timers, calls, notifications, and configurable appearance.
